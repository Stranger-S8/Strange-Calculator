# Strange Calculator

A Tkinter scientific calculator desktop application.

## Overview

Strange Calculator provides a simple GUI for arithmetic and scientific operations, including trigonometric functions, logarithms, powers, roots, and common numeric input.

## Key Features

- Desktop calculator UI
- Addition, subtraction, multiplication, and division
- Sine, cosine, tangent, and inverse trigonometric functions
- Logarithm and natural log functions
- Power/root style buttons

## Tech Stack

- Python
- Tkinter
- Python `math` module

## Project Structure

```text
.
`-- Strange Calculator.py    # Main calculator application
```

## Getting Started

```bash
python "Strange Calculator.py"
```
